ONE-TIME SETUP
Connect to Firebase 🔥
Follow these 5 steps — takes about 10 minutes. Once done, all 10 members share the same live data.
1
Create a Firebase project
Go to Firebase Console → "Add project" → name it trek-dlut-50km → disable Analytics (optional) → Create.
→ console.firebase.google.com
2
Enable Realtime Database
In your project → Build → Realtime Database → Create Database → choose a region → Start in test mode (for now).
3
Register a Web App & get your config
Project settings (⚙️) → Your apps → Add app (Web </>) → name it → Copy the firebaseConfig object.
4
Paste your config into this file
Open running_tracker_firebase.html in a text editor. Find the block below and replace every YOUR_* value:
const FIREBASE_CONFIG = {
  apiKey:            "AIzaSyDv90xPQbxhBtZ5j0exJYWcJnmI631lkr0",
  authDomain:        "trek-dlut-50km.firebaseapp.com",
  databaseURL:       "https://trek-dlut-50km-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId:         "trek-dlut-50km",
  storageBucket:     "trek-dlut-50km.firebasestorage.app",
  messagingSenderId: "842711076233",
  appId:             "1:842711076233:web:58f7d7b2892518a58ca558"
};
5
Set Realtime Database Rules
Realtime Database → Rules tab → replace with this (allows all club members to read/write):
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
⚠️ These are open rules — fine for a private club tracker. For production, add auth.
After setup, share the file
• Save this HTML file anywhere (USB drive, email, Google Drive)
• All 10 members download it & open it in Chrome/Edge/Firefox
• Everyone sees the same live data — no server needed beyond Firebase
• Or host it free on GitHub Pages for a permanent URL
